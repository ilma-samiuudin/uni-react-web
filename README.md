# University Website Landing Page (ReactJS, TailwindCSS)

A professional Frontend project built with React, Vite, and Tailwind CSS.
University website is fully responsive, modern, Educational landing page  designed for universities.

## Live Demo
You can view my live portfolio here: https://uni-react-web.vercel.app/

# Features & Tech Stack
* ReactJS - Component-based structure for smooth perfomance
* Tailwind CSS - For modern , clean and custom styling
* Fully Responsive - Optimized for mobile, tablet, desktop
* Key Sections - Home, About Us, Courses/Programs, Campus Life and admissions

## How to Run locally
1. Clone the respository
2. Install dependencies: `npm install`
3. Start development server: `npm run dev`(or `npm start`)
